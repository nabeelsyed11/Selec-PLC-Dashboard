## System Overview

The **Selec MiBRX-6M Industrial IoT Edge Gateway** is a real-time monitoring and control platform designed for deployment on Raspberry Pi 5 / industrial Linux hardware. It interfaces with a physical Selec MiBRX-6M PLC over Modbus TCP (Ethernet) to collect process telemetry, perform edge signal processing, monitor machine safety interlocks, and stream data to browser dashboards at 10 Hz via WebSockets.

## Architectural Components

### 1. Modbus Client Subsystem (`backend/app/plc/`)
- **Modbus Protocol:** PyModbus 3.6.8 async TCP client connecting to Selec MiBRX-6M on port 502 (or virtual simulator port 5020).
- **Grouped Polling Engine:**
  - `fast_group` (200 ms): Emergency stop circuit, safety door interlocks, VFD run/fault status, pusher cylinder sensors, conveyor line speed.
  - `medium_group` (500 ms): Motor thermal sensors, optical part detection counter, load cell platform weighing, mains voltage & current.
  - `slow_group` (1000 ms): Cumulative kWh electrical energy, grid frequency, power factor, machine running hours.
- **Fail-Safe Disconnect Guarantee:** When Simulation is OFF and physical PLC is unreachable, all measurements are tagged `DISCONNECTED` with `0.0` values. Synthetic data is strictly barred from physical mode.

### 2. High-Frequency Vibration FFT Engine (`backend/app/vibration/`)
- **Hardware Interface:** ADXL345 digital 3-axis accelerometer connected via I2C bus 1 on Raspberry Pi GPIO.
- **Signal Analysis:** Continuous 1000 Hz sampling into an in-memory ring buffer. Computes RMS acceleration ($g$), peak acceleration, crest factor, and Fast Fourier Transform (FFT) frequency spectrum for predictive maintenance and bearing fault detection.

### 3. Edge Data Buffering & SD-Card Protection (`backend/app/database/`)
- **SD-Card Optimization:** Raspberry Pi micro-SD cards degrade quickly under high-frequency writes. The gateway aggregates measurements in an in-memory buffer (`DatabaseBuffer`) and commits writes to SQLite in 1.0-second atomic WAL transactions.
- **Data Pruning:** Automatically trims historical records older than 720 hours (30 days) to prevent disk exhaustion.

### 4. Deterministic Machine State Machine (`backend/app/state/`)
- Evaluates states in strict priority order:
  1. `COMM_LOST`: Physical Modbus TCP communication down.
  2. `FAULTED`: Emergency stop tripped, safety guard open, or VFD fault active.
  3. `RUNNING`: VFD running and conveyor speed > 0.05 m/s.
  4. `IDLE`: Permissives closed, motor not actively running.

### 5. Safe Machine Remote Control Console (`backend/app/api/routes_control.py`)
- **Hardware Allowlist:** Restricts writable actions strictly to permitted FC 05 Coils (Pusher Solenoid, VFD Run/Stop) and FC 06 Registers (VFD Speed Setpoint). Unregistered Modbus addresses are blocked with HTTP 400.
- **Interlock Enforcement:** Commands cannot be executed unless safety permissive interlocks (E-Stop OK, Guard Door Closed, VFD No-Fault) are verified closed.
- **Hardware Offline Lockout:** All command executions are blocked when physical PLC is disconnected.
